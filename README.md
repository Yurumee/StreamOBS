## Introdução
Este repositório é dedicado a desenvolver um token seguro para transmissão e visualização de tela.

## Como Funciona
Ao executar o código, ele irá gerar dois links, uma para transmissão de tela, e outro para assistir a transmissão. Os links sempre são gerados em pares.

> [!WARNING] 
>
> Tenha em mente que qualquer um com o mesmo **ID DE TRANSMISSÃO** pode entrar na mesma sala que a sua.
>
> O código gera um ID de 43 caracteres aleatórios para minimizar o máximo possível a chance de desconhecidos entrarem na sala.

Os links levam para o site [VDO.NINJA](https://vdo.ninja/), idealizado pelos criadores do [OBS](https://obsproject.com/pt-br). Quando a transmissão for iniciada, os que desejam assistir devem clicar no botão "play" no centro da tela.

> [!NOTE]
>
> Tanto para transmissão como para visualização, deve-se permitir câmera e/ou microfone (apenas selecione a opção "nenhum")
>
> Isso acontece pois pode-se utilizar isto pelo próprio site como ferramentas de reunãi como Google Meet ou Zoom.

Os links podem ser visualizados pelo terminal ou por meio do executável. Nenhuma das formas exige instalação.
